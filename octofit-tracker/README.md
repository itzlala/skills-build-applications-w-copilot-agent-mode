# OctoFit Tracker (scaffold)

This folder contains a small scaffold for the OctoFit Tracker exercise used in the GitHub Skills workshop.

Backend (Python/Django):

- Create a virtual environment and install dependencies:

```bash
python3 -m venv octofit-tracker/backend/venv
source octofit-tracker/backend/venv/bin/activate
pip install -r octofit-tracker/backend/requirements.txt
```

Frontend:

- Add a React app in `octofit-tracker/frontend` (this is left as the next step).

Notes:
- Do not change directories when running agent-mode commands; point to paths instead.
- Forwarded ports: 8000 (backend), 3000 (frontend), 27017 (mongodb, private).
